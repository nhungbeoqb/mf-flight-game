TIDE POST — a dawn mail run by seaplane. Pilot Wren Halloway flies the Kittiwake between the lighthouses of the Gull Sound: thread the storm rings, mind the fuel and the fragile cargo, and set her down on a lit strip before the tide turns. Four sorties with different goals — a ring run, a fragile delivery, a night landing, a rescue — with stars, parcels to scoop, lives, and progress saved between sessions.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network request — every file the game loads sits under game/.

## Controls

W/S throttle · I/K climb & descend · A/D or ←/→ bank & turn · P pause · M mute · click to start

Land slow (under 95 knots), wings level, lined up with the strip — or, on open water, slow and level beside a dock.
